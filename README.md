# Smart Library Management System (Team 2)

A web application written in **pure C**. The C program is the web server (using sockets) and the browser is the interface. No external libraries and no database: data is stored in text files.

## Features
- **Books:** add, edit, delete, search (ID, title, author). Fields: ID, title, author, category, publisher, year, total and available copies.
- **Members:** add, edit, delete, search. Fields: ID, name, department, year of study, phone, email.
- **Issue / Return:** due date is 1 month (30 days) after issue, maximum 3 books per member, no issue when no copies are left.
- **Overdue and fine:** books kept more than 1 month are listed as overdue, fine is Rs 2 per day.
- **Dashboard:** total books, members, issued, overdue and fine pending.
- **Download data (Excel):** one click downloads `library_data.xlsx` with Books, Members and Issues sheets (the .xlsx file is generated by the C program itself).
- Input validation with clear error messages.

## Files
| File | Purpose |
|---|---|
| `main.c` | C web server, all logic, file handling and Excel export |
| `index.html` | The web page (keep it in the same folder as the program) |
| `preview.html` | Optional demo of the page that runs without compiling (sample data only) |

## Run
**Windows (MinGW):**
```
gcc main.c -o library.exe -lws2_32
library.exe
```
**Linux / Mac:**
```
gcc main.c -o library
./library
```
Then open **http://localhost:8080**. The files `books.txt`, `members.txt` and `issues.txt` are created automatically.

## Limits
No login (demo project), up to 200 books, 200 members and 1000 issue records, single-user server.
